# Spot the Difference - Game

A JSON-configurable "Spot the Difference" game built using HTML, CSS, and JavaScript.

## 🔧 How to Run
1. Clone/download this repo.
2. Open `index.html` in a browser.
3. The game loads data from `config.json`.

## 🧠 How JSON is Used
- `config.json` defines:
  - Image paths (`image1`, `image2`)
  - A list of differences (`x`, `y`, `width`, `height`)
- The game reads this and dynamically sets up image hotspots.

## 📦 Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
